# スタンプ手動操作（MANUAL-ADJUST）の出どころ確認 - ミニアプリ開発者へ

**作成日**: 2026-06-12
**重要度**: 🟡 確認依頼
**きっかけ**: 診察券8305（宇野祥子）さんのスタンプが15になった経緯調査
**前提**: 管理ダッシュボードではなく、スマホ画面（ミニアプリ）からスタッフがスタンプ操作できると伺ったため、その機能の確認をお願いしたい

---

## 📋 背景

診察券 **8305（宇野祥子）** さんのスタンプが `15` になった経緯を、管理ダッシュボード側のログ（`activity_logs` / `event_logs` / `stamp_history`）で調査しました。

結果、スタンプ15は以下の **1レコードのみ** で記録されていました。

```
stamp_method : manual_admin
stamp_number : 15   （付与後の累積）
amount       : 15   （差分 +15）
qr_code_id   : MANUAL-ADJUST-20260610-021224
notes        : スタッフ操作: +15個 (0 → 15)
created_at   : 2026-06-10 11:12:25 (JST)
```

このユーザーの来院（QRスキャン）記録は無く、`visit_count = 0` です。
→ **来院の積み上げではなく、スタッフによる手動の一括付与** と判断しました。

---

## 🔍 管理ダッシュボード側で判明したこと

### 1. この `qr_code_id` 形式は管理ダッシュボードのコードには存在しない

管理ダッシュボードがスタンプを手動操作した場合、`stamp_history` には必ず以下の形式で記録されます。

| 操作 | qr_code_id | notes |
|------|-----------|-------|
| スタンプ数を設定（stamp-set API） | `admin-<timestamp>` | `管理ダッシュボードからスタンプ数を手動変更` |
| スタンプ増減（stamp API） | `admin-incr-<timestamp>` | `管理ダッシュボードからスタンプ増減 (+N)` |

一方、8305さんの `MANUAL-ADJUST-20260610-021224` ＋ `スタッフ操作: +15個 (0 → 15)` は、
**管理ダッシュボードのソースコードのどこにも存在しない形式** でした。

### 2. 同じ形式のレコードが他に6人（計7人）存在する

`MANUAL-ADJUST-*` 形式は8305さんだけでなく、**2026-02-21 〜 2026-06-10 にかけて計7人** に同一署名で記録されていました。

| # | 患者（診察券） | 作成日時(JST) | notes | amount列 |
|---|---|---|---|---|
| 1 | 千葉真紀子（666877） | 2026-02-21 13:09 | スタッフ操作: +2個 (0 → 2) | **10** ←不一致 |
| 2 | 木村珠奈美（3583） | 2026-03-13 21:10 | スタッフ操作: -5個 (10 → 5) | -5 |
| 3 | 小林瑠菜（6339） | 2026-03-21 11:20 | スタッフ操作: +5個 (5 → 10) | 5 |
| 4 | 物井愛恵（7260） | 2026-03-28 16:49 | スタッフ操作: -55個 (55 → 0) | -55 |
| 5 | 横山浩紀（123459） | 2026-04-04 11:51 | スタッフ操作: -20個 (20 → 0) | -20 |
| 6 | **宇野祥子（8305）** | **2026-06-10 11:12** | **スタッフ操作: +15個 (0 → 15)** | **15** |
| 7 | 伊藤弘吉（0001） | 2026-06-10 11:14 | スタッフ操作: +5個 (15 → 20) | 5 |

### 3. これらの操作は管理ダッシュボードの監査ログ（activity_logs）に残っていない

8305さん・物井さんは `activity_logs`（本人対象）が **0件** です。
管理ダッシュボードの監査ログはダッシュボード操作のみを記録するため、
**ミニアプリ側のスタッフ操作はこちらには残りません。**

## ❓ ミニアプリ開発者への確認事項

スマホ画面からスタッフがスタンプ操作できるとのことなので、以下をご確認ください。

1. **この `MANUAL-ADJUST-YYYYMMDD-HHMMSS` ＋ notes「スタッフ操作: ±N個 (X → Y)」は、ミニアプリのスタッフ機能が書き込んでいるものですか？**
   （管理ダッシュボードのものではないことは確認済みです）

2. **8305（宇野祥子）さんの 6/10 11:12 の +15個 は、スタッフによる正規の操作でしたか？**
   - 直後 11:14 に伊藤弘吉（0001）さんも同形式で操作されており、同一スタッフが 6/10 にまとめて操作した可能性が高いと見ています。

3. **`amount`（差分）列の記録について**
   - 千葉真紀子（666877）さんは notes が「+2個 (0 → 2)」なのに `amount = 10` と矛盾しています。
   - ミニアプリ側で `amount` 列に入れている値は何か（差分？固定値？）をご教示ください。
   - 集計（来院回数 `visit_count` 等）に影響する可能性があるため確認したいです。

4. **ミニアプリ側のスタッフ操作に、操作ログ（誰が・いつ）は残っていますか？**
   - 管理ダッシュボードの `activity_logs` には残らないため、別途記録があるかを確認したいです。
   - もし無い場合、誰が操作したかの追跡手段がない状態です。

5. **このスタッフ操作機能の仕様**（どの画面・どういう権限・どういう手順で実行できるか）を共有いただけると、今後の調査がスムーズになります。
